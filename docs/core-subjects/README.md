# Core Computer Science Subjects in Smart Nutrition Tracker

These documents connect textbook Computer Engineering subjects to **real code** in this repository. They are written for final-year students preparing for exams, viva and placement interviews.

Each document follows the same structure:
1. **Concepts used**: each concept explained simply, with the file where it appears and a short code excerpt.
2. **Concepts not implemented**: what an interviewer might expect, why it is missing, and how it could be added.
3. **Interview questions**: practical questions with answers tied to this project.

| Subject | Document | Strength of mapping |
|---|---|---|

| Database Management Systems | [DBMS.md](DBMS.md) | Strong |
| Operating Systems | [OPERATING_SYSTEMS.md](OPERATING_SYSTEMS.md) | Moderate |
| Computer Networks | [COMPUTER_NETWORKS.md](COMPUTER_NETWORKS.md) | Strong |
| Data Structures and Algorithms | [DSA.md](DSA.md) | Light to moderate |
| Software Engineering | [SOFTWARE_ENGINEERING.md](SOFTWARE_ENGINEERING.md) | Moderate |
| Combined interview questions | [CORE_SUBJECT_INTERVIEW_QUESTIONS.md](CORE_SUBJECT_INTERVIEW_QUESTIONS.md) | — |

**Honesty rule:** if a concept is not in the code, these documents say so. In an interview it is better to say "the project does not use X, but here is where I would add it" than to overclaim.
